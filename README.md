# NLP Chatbot Project

## About the Project

This is a simple chatbot built using Natural Language Processing (NLP) and basic machine learning.
It can understand user input and reply with the most relevant answer based on the data it was trained on.

I created this project to understand how chatbots work and how machines process human language.

---

## How it Works

* The chatbot is trained on a small set of questions and answers
* It converts text into numerical form using TF-IDF
* A machine learning model is used to predict the best response

---

## Technologies Used

* Python
* Scikit-learn
* NLP techniques (TF-IDF)

---

## How to Run the Project

1. Install required libraries:
   pip install -r requirements.txt

2. Run the chatbot:
   python main.py

3. Start chatting:
   Type your question and get a response
   Type "exit" to stop
